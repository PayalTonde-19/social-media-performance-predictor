
# Social Media Performance Predictor

## About the Project
This project aims to predict Instagram content performance using machine learning.

## Objectives
- Analyse Instagram post data.
- Identify factors affecting engagement.
- Predict content performance.
- Display results through an interactive Streamlit dashboard.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## Project Structure
- data: Dataset
- notebooks: Data analysis and experiments
- app: Application files
- app.py: Streamlit dashboard

## How to Run
Install the dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
